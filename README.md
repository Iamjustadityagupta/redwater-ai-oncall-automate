# AI-on-call-automate

**Track:** Automation · Homingo Hack Days 2026

When software breaks at 3 AM, a person still wakes up, reads logs, traces
the cause and ships a fix. The information needed is all in the logs,
metrics, code and past incidents — AI can now read all of it.

This project builds automation that watches running systems, finds the
root cause of a failure, proposes or ships the fix, and proves it worked —
so that keeping software alive needs far fewer people.

## What it does
- Watches logs/metrics for anomalies
- Diagnoses root cause using an LLM
- Proposes or applies a fix
- Re-runs tests to verify the fix worked
- Logs every step (observability)
